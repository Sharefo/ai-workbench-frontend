# SQL 实验室 · 前端（网页门店）

用大白话：这一层就是你在浏览器里看得到、点得到的部分——左边表结构、中间写 SQL、下面出结果、右边 AI 助手和练习题。它**不存数据、不执行 SQL**，只负责把你的操作发给后端，再把结果画出来。

## 为什么是纯 HTML/CSS/JS

按需求「我只负责点开网页」，前端不需要 `npm install`、不需要打包。后端启动时会把本目录的网页一起送出去，所以只用启动一个服务。

## 目录里放什么

| 文件 | 作用 |
|---|---|
| `index.html` | 页面骨架：顶栏、左侧表结构、主工作区 Tab |
| `styles.css` | 样式；照 `../docs/05-页面设计留档.md` 迭代，不每次重新描述 |
| `app.js` | 交互：切换空间/Tab、执行 SQL、流式 AI、造数预览、闯关提交、执行记录 |

## 安全规矩（阶段 0.2）

1. 前端**不存放任何密钥**；AI 调用一律由后端代理。
2. `node_modules/`、`dist/`、`.env` 不提交云端；见 `.gitignore`。
3. 所有改动提交到 `feature/v1.0.0`，**不动 main**。

## 怎么打开

后端启动后浏览器访问 **http://127.0.0.1:8765**（端口固定，写进交接本）。
